БРИДЖ РУБИКА — Render Couple v1

ЗАМЕНИ В GitHub-репозитории bridge-rubik-online:
1) server.py
2) public/index.html
3) requirements.txt
4) render.yaml

Ничего в Render перенастраивать не нужно: autoDeploy должен подхватить commit.

НОВОЕ:
- кнопка «Рубик + Лисюша + 2 бота» в Онлайн;
- при создании сервер сразу ставит Бот 1 на место №2;
- Лисюша по ссылке занимает место №3 — напротив Рубика;
- Бот 2 автоматически становится местом №4;
- хозяин нажимает «Начать игру».

Логическая рассадка:
Рубик (0) -> Бот 1 (1) -> Лисюша (2) -> Бот 2 (3)
На экране Рубика Лисюша — центральный соперник сверху, то есть напротив.
