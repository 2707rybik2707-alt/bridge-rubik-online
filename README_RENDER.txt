БРИДЖ РУБИКА — FULL ONLINE

Эта папка полностью заменяет старую версию проекта в GitHub.

В корне репозитория должны лежать:
- server.py
- render.yaml
- requirements.txt
- .gitignore
- public/index.html

Что нового:
- 1/2/3 бота с отдельной сложностью: лёгкий / средний / высокий
- онлайн 2–4 человека
- смешанные комнаты: люди + боты
- музыка: 4 встроенные темы
- звуки и громкости
- анимации, уведомления, вибрация
- история действий и очков
- корректный порядок игроков относительно каждого клиента
- серия одинаковых карт и правильный цвет мастей
- заказ масти Валетом
- закрытие комнаты хозяином

После загрузки файлов в GitHub Render должен автоматически начать новый Deploy.
Если нет: Render -> Manual Deploy -> Deploy latest commit.
